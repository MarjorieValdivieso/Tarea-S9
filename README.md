

## Sistema de Mascotas (Veterinaria)
- Registro de mascotas y vacunas
- Usa HashSet para evitar duplicados
- Usa HashMap para relacionar código y vacuna
- CRUD básico con validaciones

## Sistema de Reservas de Canchas
- Registro de clientes y reservas
- HashSet para clientes únicos
- HashMap para reservas por cliente
- CRUD: registrar, actualizar, eliminar y mostrar

## Smart Coffee
- Sistema de clientes y pedidos
- Herencia: Persona → Cliente
- HashSet para clientes sin duplicados
- HashMap para consumo por correo
- CRUD + promedio + mejor cliente

## Conceptos usados
- Herencia
- Interfaces
- HashSet
- HashMap
- CRUD
- Validaciones
